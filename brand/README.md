# Punch brand

The Punch family mark: six interwoven loops (the community — Munch, Flex and
every app after them, each linked to its neighbours) held in one ring (the
platform that encompasses them), in the same silver knotwork as the Munch tree
and the Flex knot, on a gradient from Munch's violet to Flex's blue.

| File | Use |
| --- | --- |
| `punch-icon.svg`, `punch-icon-1024.png` | App icon / avatar (gradient tile) |
| `punch-mark.svg`, `punch-mark-1024.png` | The mark alone, transparent background |
| `punch-logo.png` | Lockup (icon + "Punch" wordmark) for light backgrounds — the Auth0 sign-in pages use this URL |
| `punch-mark.png` | 64 px favicon — Auth0 favicon |
| `src/make_punch_mark.py` | Regenerates the SVGs (`python3 make_punch_mark.py`) |

Colours: gradient #2D215A → #1E3A6E → #0C4377; silver #FFFFFF → #E6E8EC → #B9BEC6;
wordmark Fraunces 650, #1F262A.
